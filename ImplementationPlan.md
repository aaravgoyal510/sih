# KrishiSetu — Farmer Net-Realization & Assured Market Decision Platform
## 1. Status and sequencing

Phase focus: farmer income → transparency → trust → FPO aggregation → infrastructure utilization → state intelligence

The old “nothing is cut” policy and equal-priority generic-marketplace tiers are superseded. Existing transaction/role infrastructure is retained; new scope must answer the driving sell-decision question.

Current evaluation baseline now includes persistent indicative-budget recommendations, visible provisional buyer trust, saved accepted agreements, operational history, durable notifications and guided multilingual farmer tasks. The initial pivot was documentation/scaffolds; subsequent implementation is described in README.md and the active schema. Calibrated forecasts, verified income attribution and live settlement remain unshipped. The gates below remain acceptance targets, not an assertion that every phase is complete.

## 2. Ordered milestones and gates

| Phase | Implementation | Exit gate |
| --- | --- | --- |
| 1 Farmer income | Normalize costs/units, feasible candidate filter, baseline, net computation and receipt/cost event design | Same-lot arithmetic tests; missing inputs abstain; no claimed uplift without receipts |
| 2 Transparency | Persist Recommendation, evidence/version/expiry, four-field card across every sell-decision route | All placements covered; expired offers revalidated; waiting unknown is supported |
| 3 Trust | Payment/cancellation/outcome evidence, TrustScore snapshots, buyer profiles, audited penalties and appeals | Exact 87 fixture; cold-start/suspension tests; shadow scores reviewed before cutover |
| 4 FPO aggregation | Consent, fee/cost allocation and per-member recommendations/settlement | Member totals reconcile; no double pooling; each member sees net benefit |
| 5 Infrastructure utilization | Dated quotes, capacity/reservation and storage/transport decision integration | Availability rechecked; booked capacity and costs measured |
| 6 State intelligence | Privacy-safe net outcomes, payment-delay and capacity-gap aggregates | Simulation excluded; sample size/coverage shown; access and privacy review |

Safety/ownership/suspension checks apply from phase 1, even though visible scoring matures in phase 3. Source health is a dependency, not a promise that Agmarknet/e-NAM/IMD are all live.
